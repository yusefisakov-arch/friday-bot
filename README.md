# Радар 999.md

Телеграм-бот, который следит за продажей квартир и домов в Кишинёве и
присылает объявления, заметно более дешёвые, чем сопоставимые предложения
в том же районе.

## Зачем

Стратегия простая: купить дёшево жильё в плохом состоянии, отремонтировать,
сдавать помесячно. Узкое место — найти такое объявление раньше других.
Бот закрывает именно его.

## Как он решает, что объявление стоит внимания

«Дёшево» — величина относительная, поэтому бот не сравнивает с абсолютной
ценой:

1. Раз в сутки строит карту рынка: медиану €/м² по каждой связке
   **город + сектор + количество комнат**, считая по случайной выборке в
   800 объявлений. Важно: в выборку идёт только такое же жильё в плохом
   состоянии — иначе любая квартира без ремонта выглядит на треть дешевле
   евроремонта, и это не находка, а её состояние.
2. Каждые 15 минут проверяет свежие объявления по подписке.
3. Присылает те, чей €/м² ниже медианы своей группы на 20% и больше,
   с пометкой, насколько именно.

Отдельно отсекаются аномалии: если цена ниже медианы больше чем на 60%,
это почти всегда опечатка или приманка «цена за долю» — такое не приходит.

## Команды

| Команда | Что делает |
|---|---|
| `/radar_here` | отправить **в группе** — заведёт темы и начнёт следить |
| `/radar` | что настроено, когда проверял, размер карты рынка |
| `/radar_check` | проверить немедленно |
| `/radar_on N`, `/radar_off N` | включить или приостановить подписку |

## Настройки по умолчанию

- Кишинёв (муниципий), продажа
- Квартиры и дома в состоянии: без ремонта, нуждается в ремонте, серый или
  белый вариант, косметический ремонт
- Потолок цены — 60 000 €
- Порог — дешевле медианы на 20%

Меняются в `radar999.py`: `DEFAULT_MAX_PRICE`, `DEFAULT_DISCOUNT`,
`COND_APT_BAD`, `COND_HOUSE_BAD`.

## Переменные окружения

| Переменная | Назначение |
|---|---|
| `TELEGRAM_TOKEN` | токен бота |
| `DATABASE_URL` | PostgreSQL |
| `ALLOWED_USER_ID` | чей Telegram ID бот слушает |
| `RADAR_INTERVAL_MINUTES` | как часто проверять, по умолчанию 15 |
| `TIMEZONE` | по умолчанию `Europe/Chisinau` |

## Файлы

| Файл | Что внутри |
|---|---|
| `bot.py` | точка входа, команды |
| `radar999.py` | клиент API 999.md, карта рынка, отбор, отправка |
| `core.py` | конфигурация, пул PostgreSQL, утилиты |

## Откуда данные

GraphQL API 999.md (`POST https://999.md/graphql`, заголовок `lang: ru`).
Не разбор HTML: переживает редизайны сайта и не упирается в капчу.
Идентификаторы фильтров и характеристик описаны в шапке `radar999.py`.
